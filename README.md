# dashboard-turismo-argentina
Proyecto académico de análisis de datos: dashboard interactivo del sector turístico argentino (2023-2025) en SAS Viya. Incluye limpieza de datos, KPIs de viajeros y ocupación hotelera, mapa de burbujas, alertas por semáforo y proyección de viajeros para el primer semestre de 2026. Contiene informe técnico y capturas.
